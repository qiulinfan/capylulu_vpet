# Retired jumping cheer

This directory preserves the five former `jumping` frames that were removed
from the active action set. The action duplicated the purpose and silhouette of
the approved `waving` success celebration.

The archive contains the five source frames, their former generation prompt and
layout guide, plus the last contact sheet from before retirement. These files
are historical draft lineage only. The independent GIF builder must not emit a
`jumping` preview, and the next whole-pet assembly must not use this action.
